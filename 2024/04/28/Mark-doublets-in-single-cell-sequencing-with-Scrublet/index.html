Mark doublet in single-cell sequencing data with Scrublet

This tool is defaultly used in AllCools workflow in snmC-seq data analysis. This article is to briefly describe the main steps and ideas used by this tool.

The workflow of Scrublet

![ workflow ](./Mark doublets in sc with Scrublet-1.png)

Steps

  1. Default preprocessing

Starting with a background-filtered, UMI-based counts matrix for the observed cells, then perform normalization, gene filtering, and principal components analysis (PCA):

a. Normalize each cell by its total counts, setting the post-normalization total to the average total of all cells.

b. Identify highly variable genes.

c. Z-score standardize the highly variable genes.

d. Run PCA (unweighted). Store the eigenvectors for transformation of simulated doublets.

  1. Doublet simulation

Doublets are simulated by adding the unnormalized counts from ramdomly sampled observed transcriptomes. Doublets transcriptomes are then transformed into the same PCA space as the observed transcriptomes through the following steps:

a. Normalize gene expression for each simulated doublet.

b. Apply the gene filter from step b of “preprocessing”.

c. Standardize the simulated data using the same gene means and standard deviations as measured in the observed transcriptomes.

d. Apply the eigenvectors from step d of “preprocessing” to embed simulated doublets in the same PCA space as the observed transcriptomes.

  1. KNN classifier

KNN graph is built using Euclidean distance in the combined PCA embedding of the observed and simulated cells. Next, $\lambda(x_i)$ and $\lambda(y_i)$, the doublet scores for the observed transcriptomes $x_i$ and simulated doublets $y_i$, respectively, are calculated by finding the fraction of each transcriptome’s neighbour that are simulateed doublets and calculating the Bayesian Likelihood.

  1. Setting the doublet score threshold

    After computing the doublet scores, a threshold $\theta$ is set based on the distribution of $\lambda(y_i)$, and observed transcriptomes with $\lambda(x_i)$ > $\theta$ are predicted as doublets.

Reference

Scrublet: Computational Identification of Cell Doublets in Single-Cell Transcriptomic Data. 2019. Cell Systems
