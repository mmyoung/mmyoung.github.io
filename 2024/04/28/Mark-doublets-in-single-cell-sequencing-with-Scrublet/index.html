Mark doublets in single-cell sequencing with Scrublet

Posted on 2024-04-28 Edited on 2026-08-06 In tool usage

Scrublet is a practical tool for flagging doublets in single-cell sequencing data. It is commonly used in the AllCools workflow for snmC-seq analysis.

Workflow

Scrublet follows four main steps:

  1. Default preprocessing
  2. Doublet simulation
  3. KNN classification
  4. Threshold setting

1. Default preprocessing

Start with a background-filtered, UMI-based count matrix for the observed cells, then perform normalization, gene filtering, and PCA:

  1. Normalize each cell by total counts, using the average total across cells as the target.
  2. Identify highly variable genes.
  3. Z-score standardize the highly variable genes.
  4. Run unweighted PCA and store the eigenvectors for simulated doublets.

2. Doublet simulation

Doublets are simulated by adding unnormalized counts from randomly sampled observed transcriptomes. The simulated transcriptomes are then transformed into the same PCA space as the observed cells:

  1. Normalize gene expression for each simulated doublet.
  2. Apply the same gene filter used in preprocessing.
  3. Standardize the simulated data with the gene means and standard deviations from the observed transcriptomes.
  4. Apply the preprocessing eigenvectors to embed the simulated doublets in the same PCA space.

3. KNN classifier

A KNN graph is built using Euclidean distance in the combined PCA embedding of observed cells and simulated doublets. Then the doublet scores are computed for both observed transcriptomes and simulated doublets.

In notation:

  • \lambda(x_i) is the score for observed transcriptome x_i
  • \lambda(y_i) is the score for simulated doublet y_i

These scores are based on the fraction of doublet neighbors and the Bayesian likelihood.

4. Threshold setting

After computing doublet scores, a threshold \theta is chosen from the distribution of \lambda(y_i). Observed transcriptomes with \lambda(x_i) > \theta are predicted as doublets.

Take-home message

Scrublet is useful when you want a principled, data-driven way to identify doublets before downstream analysis. It is especially helpful when the single-cell library contains enough cells for simulation-based scoring.

Reference

Scrublet: Computational Identification of Cell Doublets in Single-Cell Transcriptomic Data. Cell Systems, 2019.
