Study Design: Power, Effect Size, and Sample Size

Posted on 2026-08-06

This note summarizes a practical way to think about study design for biomedical and multi-omics projects. The main idea is simple: in most cases, you fix three of the four inputs and solve for the fourth.

1. Core idea

  • effect size
  • sample size
  • alpha
  • power

If one of these changes, the others usually move as well.

2. Key relationships

  • Larger effect size usually means fewer samples.
  • Higher power usually means more samples.
  • Smaller alpha usually means more samples.
  • Higher variance usually means more samples.
  • More dropout or QC failure means you should inflate the enrollment target.

  • alpha = 0.05
  • power = 0.80

If the sample size is fixed, power tells you how likely the study is to detect the assumed effect.

5. Effect size: how should I estimate it?

This is usually the most important step in study design.

Method 1: pilot study

The most recommended approach.

Example pilot:

  • Control: 10 ± 2
  • Treatment: 12 ± 2

Then:

  • d = (12 - 10) / 2 = 1.0

This effect size can be used for the main study planning.

Method 2: literature

Use a similar published study.

Example:

  • Olink IL6
  • log2FC ≈ 1
  • SD ≈ 1.5

Then:

  • d ≈ 1 / 1.5 = 0.67

Method 3: biological meaning

Start from the smallest change that is scientifically meaningful, then combine it with historical variance.

Practical note:

  • A single pilot estimate is usually not enough.
  • It is better to run optimistic, base, and conservative scenarios.

6. Olink study design: why is it more complicated?

Olink is not just one protein. It often means 3000+ proteins, so sample size depends on more than a simple t-test.

Important factors:

  • multiple testing
  • FDR
  • assay variance
  • missing values
  • paired or unpaired design
  • repeated measures

For mixed models or multi-protein designs, simulation-based power analysis is often the most realistic approach.

Simple CRP example

Suppose:

  • target protein: CRP
  • expected difference: 0.5 NPX
  • historical SD: 0.8 NPX

Then:

  • d = 0.5 / 0.8 = 0.625

7. Quick pilot-study checklist

  • Define the primary endpoint first.
  • Choose the smallest meaningful effect.
  • Estimate variance from pilot data or the closest available source.
  • Set alpha, power, and sidedness before collecting data.
  • Adjust for dropout, QC failure, and multiple testing.
  • Use simulation when the design is too complex for a closed-form formula.

8. Olink note

Olink NPX values are log2-scale relative abundance values, so effect sizes and variance should be interpreted on that scale.
