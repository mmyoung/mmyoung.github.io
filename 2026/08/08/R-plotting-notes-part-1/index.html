5. Arrows and annotations

Base graphics can annotate a figure directly with arrows() and grid::arrow().

The note also compares arrow head size and angle.

A useful trick for highlighting part of a plot is to draw a translucent rectangle behind it.

Take-home message

Most of these examples are small, but they save time in real analysis work. The main pattern is simple: keep the statistical logic separate from the visual polish, then add the polish only after the figure is already correct.
