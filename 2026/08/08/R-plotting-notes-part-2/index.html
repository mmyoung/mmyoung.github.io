R Plotting Notes II: Correlation, Lollipop Plots, Odds Ratio Bars, Donuts, Facets, and Circos

Posted on 2026-08-08 In R plot archive

This second part groups the more advanced and presentation-style plots from the original Evernote note.

1. Correlation plots and Venn diagrams

The note starts with examples of correlation-focused visualization and then moves to a Venn diagram example.

2. Annotating a regression equation

One practical trick is to place a fitted equation directly on the figure.

3. Lollipop plots

A lollipop plot is a compact way to show proportions or ratios.

4. Odds ratio bar plots

The note includes a standard odds-ratio bar plot and a cleaner version with values displayed inside the bars.

5. Donut plot

A donut plot can be built with coord_polar() after preparing cumulative proportions.

6. Facets with independent axes

When facet_grid() is too restrictive, ggforce::facet_row() gives more freedom for per-panel scales.

7. Stacked bar plots with custom palettes

The note ends with a useful helper for generating a multi-level color palette for stacked bars.

8. Circos plot

Finally, the note shows a practical circlize example for genomic tracks.

Take-home message

This part is mostly about presentation. The core lesson is that a good plot is usually built in layers: start with the data structure, then add scale control, labels, color, and layout only after the main message is clear.
